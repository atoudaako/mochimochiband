# もちもちバンド

もちこけし13体をステージに並べて、リズム・ベース・メロディ・ボイスを重ねて曲を作る、スマホ横画面向けの音楽ゲームです。
13体目の「オコゲ」をステージに乗せるか「変身」ボタンを押すと、全員がホラー風の姿と音に変わります。

- HTML 1枚と音声ファイルだけで動きます(ビルド不要・外部ライブラリなし)
- 各キャラの設定は、ゲーム内の「図鑑」から読めます

## 遊び方

| 操作 | 内容 |
|---|---|
| 下のキャラをステージへドラッグ(またはタップ) | そのキャラが歌い始めます。次の小節の頭から入るので、リズムがずれません |
| ステージのキャラをタップ | ミュート/解除 |
| × ボタン | ステージから外す |
| 4種類をそろえる | コンボ演出 |
| オコゲを乗せる/「変身」ボタン | 変身モード。オコゲを外すか「もどる」で元に戻ります |
| 全画面 | 全画面表示の切り替え(iPhone の Safari は非対応。「ホーム画面に追加」で全画面になります) |
| おまかせ | ランダムな編成 |

## ローカルで動かす

音声ファイルを `fetch` で読み込むため、`index.html` をダブルクリックで開くだけでは音が鳴りません。簡単なサーバーを立てて開いてください。

```sh
python3 -m http.server 8000
# → http://localhost:8000/ を開く
```

## GitHub Pages で公開する

1. このフォルダの中身をリポジトリのルートに置いて push します
2. リポジトリの Settings → Pages で、Source を「Deploy from a branch」、Branch を `main` / `/ (root)` にして保存します
3. 表示された URL を開きます。音はスマホでも、最初にどこかをタップしたあとに鳴り始めます

## ファイル構成

```
index.html              ゲーム本体(描画・再生エンジン・口パクのタイミングを含む)
audio/
  r1_n.mp3 … x1_n.mp3   通常版のループ(13本)
  r1_h.mp3 … x1_h.mp3   変身版のループ(13本)
  drone_h.mp3           変身中の環境音ループ
  sting_on.mp3          変身するときの効果音
  sting_off.mp3         元に戻るときの効果音
tools/render/
  render.html           音を合成するシンセ(Web Audio)。書き出し専用
  render.py             render.html をヘッドレスブラウザで動かして MP3 に書き出す
  hits.json             書き出し時に記録した口パクのタイミング
  update_hits.py        hits.json を index.html に埋め込み直す
```

ファイル名の `r` / `b` / `m` / `v` はリズム・ベース・メロディ・ボイス、`x1` はオコゲ、末尾の `_n` は通常版、`_h` は変身版です。

## 音声ファイルの仕様

すべてのループは次の形式です。自分で録った素材に差し替えるときもこれに合わせてください。

- 104 BPM・4小節(16分音符 × 64 = 約 9.2308 秒)
- ループ本体の前後に 0.25 秒ずつ、ループの続き(前はループ末尾、後ろはループ先頭)を余白として入れる。ファイル全体の長さは約 9.7308 秒
- モノラル、MP3 80kbps。音割れを防ぐため、ゲーム側で 2 倍に持ち上げる前提で半分の音量で書き出しています

前後の余白は、MP3 の頭に入る無音で継ぎ目が切れないようにするためのものです。ゲームは余白の内側だけをループ再生します。

## 音を作り直す

合成音を調整して書き出し直す場合の手順です。Python 3、[Playwright](https://playwright.dev/python/)(Chromium)、ffmpeg(libmp3lame 付き)が必要です。

```sh
pip install playwright
playwright install chromium
python3 tools/render/render.py audio        # 29 本の MP3 と hits.json を書き出す
python3 tools/render/update_hits.py         # 口パクのタイミングを index.html に反映
```

書き出しは 41,600 Hz で行い、ffmpeg で 44,100 Hz に変換しています。41,600 Hz なら 16 分音符がちょうど 6,000 サンプルになり、ループの継ぎ目がサンプル単位で一致するためです。
